Public API

Read your own business data from Platform-X using a secure, scoped API key.

Authentication

Send your API key in the X-API-Key header with every request. Keys are tenant-scoped: they only read the tenant they belong to. Create keys in the business panel under API & Webhooks. 

X-API-Key: pk_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Scopes

Each key carries scopes. Missing scope yields 403.

ScopeAllows
read:servicesGET /api/v1/services and /services/{id}
read:bookingsGET /api/v1/bookings and /bookings/{id}
read:reviewsGET /api/v1/reviews
read:analyticsGET /api/v1/analytics/summary
write:webhooksReserved for future write operations

Endpoints

MethodPathScope
GET/api/v1/me(any valid key)
GET/api/v1/services?page=1&page_size=20&status=activeread:services
GET/api/v1/services/{id}read:services
GET/api/v1/bookings?page=1&page_size=20&status=confirmedread:bookings
GET/api/v1/bookings/{id}read:bookings
GET/api/v1/reviews?page=1&page_size=20read:reviews
GET/api/v1/analytics/summary?days=30read:analytics

Example — Python

import requests

API_KEY = "pk_live_..."
BASE = "https://your-platform-x.example"

r = requests.get(
    f"{BASE}/api/v1/analytics/summary",
    params={"days": 30},
    headers={"X-API-Key": API_KEY},
    timeout=10,
)
r.raise_for_status()
print(r.json())

Example — JavaScript (fetch)

const API_KEY = "pk_live_...";
const BASE = "https://your-platform-x.example";

const res = await fetch(`${BASE}/api/v1/services?page=1&page_size=20`, {
  headers: { "X-API-Key": API_KEY },
});
const data = await res.json();
console.log(data.items);

Example — cURL

curl -sS \

Webhooks

Register a URL in API & Webhooks. Platform-X sends signed POST requests for the events you select.

Headers sent:

X-PlatformX-Event: booking.created
X-PlatformX-Signature: sha256=<hmac_sha256_hex>
Content-Type: application/json

Signature verification (Python):

import hmac, hashlib, json

def verify(raw_body: bytes, signature_header: str, secret: str) -> bool:
    expected = "sha256=" + hmac.new(
        secret.encode(), raw_body, hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, signature_header)
