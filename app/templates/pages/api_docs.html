Public API (X-API-Key)

Read your own business data from Platform-X using a secure, scoped API key. Keys are tenant-scoped: they only read the tenant they belong to. Create keys in Business Panel → API & Webhooks. 

X-API-Key: pk_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Webhooks

Platform-X can POST to your endpoint when events happen. Every request carries an HMAC-SHA256 signature header.

X-PlatformX-Signature: sha256=<hex>

Events emitted:

  • booking.created
  • booking.confirmed
  • booking.cancelled
  • payment.paid
  • review.created
  • review.responded

Verify signature in Python:

import hmac, hashlib
expected = hmac.new(secret, request.body, hashlib.sha256).hexdigest()
assert hmac.compare_digest("sha256=" + expected, request.headers["X-PlatformX-Signature"])

Error Codes & Rate Limits

CodeMeaning
400Bad request (validation or business rule)
401Missing or invalid token
403Missing scope or role
404Not found (or cross-tenant isolation)
409Conflict (state change not allowed)
422Schema violation
429Rate limited
503AI disabled or upstream unavailable

Rate limits are enforced per authenticated user (or per IP for public endpoints). Typical limits: 60/min reads, 30/min writes, 10–15/min AI.
