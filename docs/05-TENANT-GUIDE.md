# Platform-X — Tenant Guide

> Guide for businesses wanting to join Platform-X.
> Explains onboarding, pricing, and ongoing operations.

---

## 1. What is a Tenant?

A tenant is a business that operates on Platform-X.

**Examples:**
- A hotel
- A restaurant
- An entertainment center
- A travel agency

Each tenant gets:
- Own branded website
- Own admin dashboard
- Own guest database
- Own services and pricing

But shares infrastructure:
- Authentication
- Payments
- Notifications
- Analytics
- AI features

---

## 2. Why Join Platform-X?

### For Travel Agencies

## 3. Onboarding Process

### Step 1 — Business Registration
- Sign agreement with Platform-X
- Provide business documents (trade license, etc.)
- Provide branding (logo, colors)

### Step 2 — Configuration
- Set services (rooms, menu, treatments)
- Set prices
- Set policies (check-in, cancellation)
- Configure loyalty program

### Step 3 — Domain Setup
- Choose: subdomain (yourname.platformx.com) OR custom domain (yourhotel.com)
- If custom: DNS configuration
- SSL certificate provisioned automatically

### Step 4 — Data Import (optional)
- Import existing customers
- Import existing bookings
- Import room/table inventory

### Step 5 — Testing
- Test booking flow
- Test payments
- Test notifications

### Step 6 — Training
- Staff training (front desk, kitchen, spa, etc.)
- Admin training

### Step 7 — Go Live
- Announce to customers
- Begin accepting bookings

**Typical onboarding: 4-6 days (Phase 1-3), 1 day (Phase 4+).**

## 5. Commission Model

Each booking generates revenue split:

- **Tenant share:** majority (e.g., 90-95%)
- **Platform share:** (e.g., 5-10%)

**Split is automatic** at payment time (if payment provider supports it).

If not, monthly settlement based on reports.

- Booking history
- Customer insights
- Payment records

## 12. Migrating from Another System

If tenant is currently on:
- **Booking.com / Agoda:** keep both during transition, migrate gradually
- **Another PMS:** export data, import via our tool
- **No existing system:** start fresh

**Migration support included in Professional and Enterprise tiers.**

## 13. Security for Tenants

- Data isolation: your data is never mixed with other tenants
- Encryption: at rest and in transit
- Backups: daily, restorable
- Access logs: all admin actions logged
- Two-factor authentication: available for admin accounts
