## 1. Strategic Position

**North Star:**
Platform-X must be *more attractive and better than Agoda and Booking.com
in every dimension* — not just an alternative, but a superior product.

**Reference competitors:**
- Booking.com (leader in Europe/global)
- Agoda (leader in Asia/Middle East)

**Our strategic stance:** "AI-First Hospitality Platform"
(Strategy B, chosen 2026-09-29)

Rationale:
- Strategy A (clone Booking.com but cheaper) = losing race, they have
  billions and 20-year head start.
- Strategy C (B2B only) = long sales cycles, slow growth.
- Strategy B (AI-first for both guests AND businesses) = unique
  positioning, advertisable to both sides, fast growth.

## 5. Anti-Features (What We Will NOT Build)

Do NOT build these — they add cost and complexity with no user value:

- Social features (follow, posts) — Booking.com doesn't have them
- Forum / community — needs 24/7 moderation
- Video reviews — high storage cost
- Blockchain / NFT — no hospitality value
- Crypto payments — < 1% of users
- Human live chat (non-AI) — high staffing cost
- Virtual currency loyalty — complexity without value
- Auction-based booking — wrong model for hotels

## 7. Business Rules

1. **Wave 0 is a hard prerequisite** for any advertising.
   Do NOT advertise without VPS + Payment + Search + Calendar.

2. **Every feature must answer:** "Does this make Platform-X more
   attractive to either guests OR businesses than Booking/Agoda?"
   If no → reject.

3. **AI-first policy:** Any new feature must consider AI augmentation.
   Example: search gets an "AI-powered query" alongside classic filters.

4. **Do NOT build competitors' features without our angle.**
   Example: don't build a "reviews" page — build "Trust Score + AI Review
   Responder + Verified Guest Reviews". Better, not equal.

5. **Wave order is authoritative.** Do not jump waves without explicit
   user approval and clear reasoning.

6. **Every wave ends with:** milestone tag, HANDOFF update, full backup,
   smoke tests green.

- Site loads in < 2s on mobile

- A user can find a business using a map + filters

- Save to wishlist

- AI Trip Memory delivers a personalized suggestion

**Wave 3 success:**
- AI Voice Booking completes > 100 bookings in a month
- AI Auto-Repricing adopted by > 20% of businesses
- Instant Refund reduces support load by > 30%

**Wave 4 success:**
- 5+ businesses from Booking.com/Agoda migrated
- Multi-property adoption by 3+ chains
- Monthly GMV > $50,000

**Wave 5 success:**
