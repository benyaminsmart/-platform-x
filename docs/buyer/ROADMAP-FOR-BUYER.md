# Platform-X — Roadmap for the Buyer

## Immediate (Week 1)
1. Deploy to VPS (scripts/deploy/install.sh)
2. Configure .env + run migrations + seeds
3. Smoke test passes
4. SSL live (certbot)
5. Add first business tenant

## Short term (Month 1)
1. Payment production (Telr or Stripe)
2. Onboard 3-5 real businesses
3. Verify rewards + referral flows with real users
4. Add CI (GitHub Actions: run pytest on push)

## Medium term (Quarter 1)
1. Business onboarding tools (self-serve signup + KYC)
2. Mobile app (React Native or Flutter; API is ready)
3. Metrics + alerting (Prometheus + Grafana or Datadog)
4. Real AI provider connected (Gemini / OpenAI / Anthropic)

## Long term (Year 1)
1. Business-owner rewards module (separate from user rewards)
2. Regional expansion (multi-currency, multi-language already supported)
3. Partnerships (payment, travel, hospitality chains)
4. Consider mobile-app-first launch in a specific market

## Revenue levers
- Commission on bookings (default 6%)
- Featured placements
- Bundle deals margin
- Partner-funded rewards
- Paid subscription for premium business tools (future)

## Exit options
- Sell to a larger OTA / hospitality group
- Sell to a SaaS rollup
- Keep and grow to recurring revenue
